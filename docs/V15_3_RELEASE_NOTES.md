# BAM Dealer Enterprise v15.3

## Editable Invoices
- New Invoice Centre with search and status filters.
- Edit saved vehicle sale invoices without changing the invoice number.
- Update buyer details, sale totals, deposits, costs, trade-in, warranty, payment method and notes.
- Draft, Sent, Paid and Cancelled invoice statuses.
- Required reason-for-change field.
- Invoice edit history and audit-log entry for every update.
- Edit button on invoice print view and asset workspace.
