Use the dedicated mobile command centre from Safari or Chrome.

Open Mobile Operations

Cloud / Azure Access

  1. Open BAM on your phone using your normal secure Azure website.
  2. Sign in with your normal BAM account.
  3. Open Mobile Operations.
  4. Bookmark this address:
{{ mobile_url }}

The mobile workspace gives you VIN/vehicle lookup, QR and barcode part scanning, camera photo capture and workshop clock on/off.

Add BAM to the Home Screen

  1. Open {{ mobile_url }} in Safari.
  2. Tap the Share button.
  3. Tap Add to Home Screen.
  4. Name it BAM Dealer and tap Add.

BAM v24.5 includes an installable web-app manifest so the Mobile Operations screen opens like an app.

Local development

If you are running BAM directly from the Windows computer on the same Wi-Fi, the local mobile address is:

{{ local_mobile_url }}
