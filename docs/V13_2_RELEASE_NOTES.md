# BAM Dealer Enterprise v13.2

- Added **Edit Vehicle** to every saved vehicle.
- Edit stock number, status, purchase details, vehicle details, registration, roadworthy and service information.
- Replace the main vehicle photo without creating a duplicate vehicle.
- Added Save Changes, Save & Continue Editing, and Cancel actions.
- Vehicle edits are recorded in the audit log.
- Increased the upload request limit to 100 MB and added a friendly large-upload message.
- Improved the vehicle editor for iPhone and tablet screens.
