# BAM Dealer Enterprise v13.3

## Cars, Caravans & Boats
- Added Asset Type: Car, Caravan, Boat, Motorcycle, Trailer and Other.
- Added caravan specifications: length, tare, ATM, GTM, berths, axles and features.
- Added boat specifications: hull, HIN, engine, hours, horsepower, fuel, capacity, trailer and features.
- Added inventory filtering by asset type.
- Updated add/edit/detail/inventory screens for mixed stock.
- Existing vehicle records automatically remain classified as Car.
