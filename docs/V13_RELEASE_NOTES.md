# BAM Dealer Enterprise v13

## Dealer Command Centre

- New daily command-centre dashboard.
- Priority and overdue task panel.
- Workshop status board for Open, In Progress, Waiting Parts and Completed jobs.
- Registration, service, low-stock, missing-photo and ready-to-advertise alerts.
- Parts retail value and current-month parts-sales metrics.
- Quick launch controls for vehicles, parts, contacts, tasks, finance and reports.
- Responsive dashboard improvements for desktop, tablet and mobile.

## Data safety

v13 uses the existing BAM database and performs additive migrations only. Keep a backup of the previous version before changing over.
