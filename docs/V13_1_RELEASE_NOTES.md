# BAM Dealer Enterprise v13.1

## Shipping Centre
- Create part shipments with customer and address details.
- Link shipments to parts and optionally deduct inventory automatically.
- Record courier, tracking number, parcel weight, dimensions and freight charges.
- Packing checklist for invoice, wrapping, box sealing and tracking notification.
- Shipment statuses: Ready to Pack, Packed, Sent, Delivered and Cancelled.
- Printable address label and packing slip.
- Shipping dashboard with freight margin and dispatch counts.

## iPhone access
- BAM now listens on the private local network (`0.0.0.0:5000`).
- The iPhone Access page displays the correct local-network address.
- Includes instructions for adding BAM to the iPhone Home Screen.
- Intended for devices on the same trusted Wi-Fi network only.
